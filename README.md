# adv_interface_wk09

Advanced Interface, week 9: Buttons.

| Set | Tone | Concept | Prototype |
|---|---|---|---|
| 1 | Playful | **Pinball Slab**: one grey slab, one recessed channel, one porcelain ball; emphasis only changes the shell around them (primary: the channel is already the accent; secondary: the grey slab; tertiary: no shell, a hairline). **Hold to send** works like a plunger: hover and the ball swallows the slab, hold and it winds back while the channel fills, let go early and it springs back, hold through and it fires, then “Tap to undo” for 3 s (a ring drains round the ball; tap and it springs back, Unsent), then ✓✓ Delivered. Comes as icon + text, text only and icon only. **Quantity**: tap an end and the ball is thrown there, the number rolls over with it and changes on the hidden side; the slab recoils and flashes on impact; hold and it pins and counts, faster and faster; 0 and 99 are walls. Presets (1 / 2 / 5 / 10) are the button group, single select. ← → switches between the two; emphasis, structure and state are picked underneath | [Open](https://dakotashao.github.io/adv_interface_wk09/pinball-slab/) |
| 2 | Playful | **Lumen**: every button is a small light. Hover and it tilts toward the cursor while a light follows it across the surface; press and the icon leaves, travels and lands in the count as the +1, then the number rolls. Each action has its own short story: the bell sleeps until you hover and rings when pressed, the star rolls into the number and fills the button from there (tertiary → primary), the heart snaps up and stamps the count, the bookmark flips and drops in, Dislike runs away five times before giving up. The label box follows the word, so Follow → Following slides the count along. Levels: primary filled, secondary tinted, tertiary a hairline lit by your cursor; icon + text, text, icon and a single-select group, each through default, hover, pressed and disabled, then in use (dialog, over a photo, view switcher). Dark and light | [Open](https://dakotashao.github.io/adv_interface_wk09/lumen/) |
| 3 | Playful | **Ceiling**: one add button. Hover and the pill collapses into one plus while its label slides out as a tag; press and the plus turns a quarter and shoots the new item straight up, where it snaps onto the ceiling, crisp, no bounce. The first item sticks to the ceiling and each next one sticks under the one before, slightly off-line like real things stuck in place. Five is the limit: the sixth shot knocks the whole stack down and takes the ceiling. Tall strip screen, lime on near-black, disabled toggle top right | [Open](https://dakotashao.github.io/adv_interface_wk09/ceiling/) |

Each set lives in its own folder with a self-contained index.html. Spec is inside each prototype (Spec button).
