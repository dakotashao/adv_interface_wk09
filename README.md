# adv_interface_wk09

Advanced Interface, week 9: Buttons.

| Set | Tone | Concept | Prototype |
|---|---|---|---|
| 1 | Playful | **Pinball Slab**: one grey slab, one recessed channel, one porcelain ball; emphasis only changes the shell around them (primary: the channel is already the accent; secondary: the grey slab; tertiary: no shell, a hairline). **Hold to send** works like a plunger: hover and the ball swallows the slab, hold and it winds back while the channel fills, let go early and it springs back, hold through and it fires, then ✓ Sent and ✓✓ Delivered. Comes as icon + text, text only and icon only. **Quantity**: tap an end and the ball is thrown there, the number rolls over with it and changes on the hidden side; the slab recoils and flashes on impact; hold and it pins and counts, faster and faster; 0 and 99 are walls. Presets (1 / 2 / 5 / 10) are the button group, single select. ← → switches between the two; emphasis, structure and state are picked underneath | [Open](https://dakotashao.github.io/adv_interface_wk09/pinball-slab/) |

Each set lives in its own folder with a self-contained index.html. Spec is inside each prototype (Spec button).
